# ThruFlow 1.2.0

[Download on the App Store](https://apps.apple.com/app/id6798609191)

Released on GitHub on September 8, 2026 (JST). App version **1.2.0**, build **10**.

## Timers

- Adjust rest with the same −5 and +5 controls used for focus on Mac, iPhone,
  Apple Watch, and expanded Dynamic Island. At least one minute remains;
  adjusted long rests keep their long-rest behavior.
- Timer rings and the active Elastic timeline animate duration and focus-mode
  changes, with recorded time distinguished from the remaining plan.
- Paused timer controls and rings use the rest color; focus overtime keeps the
  selected Area color.
- The minimal Dynamic Island timer correctly counts down and drains its ring
  when another Live Activity shares the Island.

## Tasks and statistics

- Recognized quick-input values appear as removable chips in the iPhone Task
  composer, matching the Mac experience.
- Title-history suggestions are available above the iPhone Task edit form.
  Choosing a suggestion changes only that Task's title.
- Adjacent-month boundary cells in Month Dots are crossed out so they cannot be
  confused with empty days in the selected month.

## Compatibility

- Source APIs and documentation now consistently use Area; the Statistics CSV
  column is named `area` instead of `direction`. Update scripts that read the
  previous CSV header.
- Existing SwiftData/CloudKit entity and relationship names remain unchanged.
  Existing local and synchronized data requires no migration for the rename.
- Debug and Production data stores are separated to avoid Development CloudKit
  metadata suppressing a later Production History export. The existing
  Production store remains in place.

Apple Reminders and Todoist connectors belong to upcoming 2.0 development and
are not included in 1.2.0. This GitHub release provides source archives; official
signed binaries are distributed through the App Store.
