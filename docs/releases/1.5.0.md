# ThruFlow 1.5.0 — App Store What's New draft

Proposed copy for review. These are release notes drafts; publication is not confirmed.

## 日本語

- 統計画面を見やすく再設計し、集中時間やタスクの傾向を確認しやすくしました。
- 画面の切り替えやデータの読み込みを改善し、操作への応答を速くしました。
- 週間目標のある習慣に休息日を設定できるようになりました。達成状況も週間目標に沿って表示されます。
- Macのタスク編集画面を使いやすく改善しました。
- ThruFlowの通知サーバーを使うか、この端末内で通知を予約するか選べるようになりました。

## English

- Redesigned Statistics to make focus time and task trends easier to explore.
- Improved screen transitions and loading responsiveness.
- Set rest days for weekly Habit goals, with progress measured against the weekly target.
- Refined the Task editor on Mac.
- Added a setting to use the ThruFlow notification server or schedule notifications on this device.

## Русский

- Улучшена статистика: стало проще просматривать время фокусировки и динамику задач.
- Улучшены переходы между экранами и скорость загрузки данных.
- Для недельных целей привычек можно задать дни отдыха; прогресс рассчитывается с учётом недельной цели.
- Улучшен редактор задач на Mac.
- Добавлена настройка, позволяющая использовать сервер уведомлений ThruFlow или планировать уведомления на этом устройстве.

## 简体中文

- 重新设计了统计页面，更方便查看专注时间和任务趋势。
- 优化了页面切换和数据加载响应。
- 每周目标习惯现在可以设置休息日，进度会按每周目标计算。
- 改进了 Mac 上的任务编辑器。
- 新增通知方式设置，可选择使用 ThruFlow 通知服务器，或在本机安排通知。

## 繁體中文

- 重新設計統計頁面，更方便查看專注時間和任務趨勢。
- 改善頁面切換與資料載入的回應速度。
- 每週目標習慣現在可以設定休息日，進度會依每週目標計算。
- 改進 Mac 上的任務編輯器。
- 新增通知方式設定，可選擇使用 ThruFlow 通知伺服器，或在本機排程通知。
