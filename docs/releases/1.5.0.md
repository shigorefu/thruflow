# ThruFlow 1.5.0 — App Store release notes

The five-language text and screenshots were saved in App Store Connect and
reused with SDK 27.2 build 17. Both iOS and macOS were submitted on 2026-11-25
and read back as Waiting for Review. This is not a published App Store release.
See the [delivery and submission record](../RELEASE.md#sdk-27-rebuild-150-17--2026-11-25)
for source, toolchain, verification and submission evidence.

## What's New

### 日本語

- 統計画面とフロー画面の統計表示を見直し、集中時間やタスクの傾向をより確認しやすくしました。
- 画面の切り替えやデータの読み込みを改善し、操作への応答を速くしました。
- 週間目標のある習慣に休息日を設定できるようになりました。達成状況も週間目標に沿って表示されます。
- Macのタスク編集画面を使いやすく改善しました。
- ThruFlowの通知サーバーを使うか、この端末内で通知を予約するか選べるようになりました。

### English

- Redesigned Statistics and the statistics card on the Flow screen to make focus time and task trends easier to explore.
- Improved screen transitions and loading responsiveness.
- Added the ability to set rest days for weekly Habit goals, with progress measured against the weekly target.
- Refined the Task editor on Mac.
- Added a setting to use the ThruFlow notification server or schedule notifications on this device.

### Русский

- Улучшено отображение статистики, в том числе на экране Flow: стало проще просматривать время фокусировки и динамику задач.
- Улучшены переходы между экранами и скорость загрузки данных.
- Для недельных целей привычек можно задать дни отдыха; прогресс рассчитывается с учётом недельной цели.
- Улучшен редактор задач на Mac.
- Добавлена настройка, позволяющая использовать сервер уведомлений ThruFlow или планировать уведомления на этом устройстве.

### 简体中文

- 重新设计了统计页面和 Flow 页面上的统计卡片，更方便查看专注时间和任务趋势。
- 优化了页面切换和数据加载响应。
- 设有每周目标的习惯现在可以设置休息日，进度会按每周目标计算。
- 改进了 Mac 上的任务编辑器。
- 新增通知方式设置，可选择使用 ThruFlow 通知服务器，或在本机安排通知。

### 繁體中文

- 重新設計統計頁面和 Flow 頁面上的統計卡片，更方便查看專注時間和任務趨勢。
- 改善頁面切換與資料載入的回應速度。
- 設有每週目標的習慣現在可以設定休息日，進度會依每週目標計算。
- 改進 Mac 上的任務編輯器。
- 新增通知方式設定，可選擇使用 ThruFlow 通知伺服器，或在本機排程通知。

## Description addendum

Append the paragraph for each locale to the existing iOS and macOS app descriptions, after the existing local storage and iCloud text.

### 日本語

MacとiPhone/iPadでは、デフォルトでThruFlowの通知サーバーを使用し、端末内の通知を予備として設定します。設定から端末ごとにサーバーをオフにし、通知を端末内だけで予約することもできます。タスク名やメモは通知サーバーに送信されません。

### English

On Mac and iPhone/iPad, ThruFlow uses its notification server by default, with on-device notifications as a fallback. You can turn off the server for each device in Settings and schedule notifications locally only. Task names and notes are not sent to the notification server.

### Русский

На Mac и iPhone/iPad по умолчанию используется сервер уведомлений ThruFlow с резервными уведомлениями на устройстве. В настройках на каждом устройстве можно отключить сервер и планировать уведомления только локально. Названия задач и заметки не отправляются на сервер уведомлений.

### 简体中文

Mac 和 iPhone/iPad 默认使用 ThruFlow 通知服务器，并在设备上安排备用通知。你可以在设置中按设备关闭服务器，仅在本机安排通知。任务名称和备注不会发送到通知服务器。

### 繁體中文

Mac 和 iPhone/iPad 預設使用 ThruFlow 通知伺服器，並在裝置上安排備用通知。你可以在設定中逐一為裝置關閉伺服器，只在本機安排通知。任務名稱和備註不會傳送至通知伺服器。
