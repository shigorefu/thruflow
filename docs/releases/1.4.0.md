# ThruFlow 1.4.0

Draft release notes — build 14. Not yet published.

## New

- One optional Habit per Project, with an independent goal and schedule; Project editors no longer show memo or ordinary Task creation.
- Task creation hides Project selection when the Area has no Projects.
- Habit completion statistics include partial progress and a per-Habit breakdown.

- Optional Task times and reminders, with `9:00` quick input, native controls and reminders enabled by default for newly assigned times.
- Optional Projects shown beneath their Areas, with task assignment, completion and reopening on Mac and iPhone/iPad. Choose an available Project when finishing Flow; Watch supports task assignment.

- Simplified and Traditional Chinese support across Apple devices.
- Selecting an Area for focus creates an unnamed Task; name it when finishing
  and add a note about what you accomplished.
- Timer rings preserve each Area color when switching Tasks during a Flow.

## Improvements

- Horizontal onboarding and iPad-style expanded iPhone Duo layouts, with adaptive navigation and task drafts preserved while changing display size. Expanded Areas shows three groups together; the mobile timer keeps its dial beside the controls.

- Colored Project tiles connect to Area emoji icons as a tree, while Areas without Projects retain the simple layout.

- Unnamed Tasks display their Project name with an Area emoji; Flow rows also show Area/Project subtitles, and Statistics adds a Project breakdown.

- Rest recommendations account for consecutive focus blocks and actual breaks.
- Task and Area editing now behaves consistently across Mac and iPhone/iPad.
- Toggl setup distinguishes connection from enabled export and explains sending
  results, unsaved settings and unavailable device identity.
- Mac appearance settings use a native dropdown.

## Fixes

- Mac month pickers use localized month names instead of numeric captions in English and Russian, including accessible month/year labels.

- Incomplete weekly Habits start fresh on the next eligible day, preserving earlier progress and history.

- Archived Areas can be restored on Mac and iPhone/iPad without losing Tasks or Flow history.
- Archived Habit Areas stop producing unused future Tasks.
- Mac quick Task forms close with their host window.
- Failed saves restore displayed values, including on macOS 26, while preserving
  unrelated pending edits.
- Editors preserve unnamed/undated Tasks, hashtags, live progress and current Areas.

## Connector scope

Connectors remain in beta. Toggl exports eligible completed Flows started on the
originating device after activation, using configured Area/project mappings.
Past records are not automatically backfilled; later edits and deletions in
ThruFlow are not propagated to Toggl.

on 2026-10-16; the Task-time/reminder fields followed on 2026-10-18. Signed archives,
upload history, physical-device synchronization and notification-delivery checks
