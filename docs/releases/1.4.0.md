# ThruFlow 1.4.0

Draft release notes — build 13. Not yet published.

## New

- Optional Task times and reminders, with `HH:mm` quick input and native controls across Mac, iPhone/iPad and Watch.
- Optional Projects within Areas, with task assignment, completion and reopening on Mac and iPhone/iPad; Watch supports task assignment.

- Simplified and Traditional Chinese support across Apple devices.
- Selecting an Area for focus creates an unnamed Task; name it when finishing
  and add a note about what you accomplished.
- Timer rings preserve each Area color when switching Tasks during a Flow.

## Improvements

- Rest recommendations account for consecutive focus blocks and actual breaks.
- Task and Area editing now behaves consistently across Mac and iPhone/iPad.
- Toggl setup distinguishes connection from enabled export and explains sending
  results, unsaved settings and unavailable device identity.
- Mac appearance settings use a native dropdown.

## Fixes

- Archived Areas can be restored on Mac and iPhone/iPad without losing Tasks or Flow history.
- Archived Habit Areas stop producing unused future Tasks.
- Mac quick Task forms close with their host window.
- Failed saves restore displayed values, including on macOS 26, while preserving
  unrelated pending edits.
- Editors preserve unnamed/undated Tasks, hashtags, live progress and current Areas.

## Connector scope

Connectors remain in beta. Toggl exports eligible completed Flows started on the
originating device after activation, using configured Area/project mappings.
Past records are not automatically backfilled; later edits and deletions in
ThruFlow are not propagated to Toggl.

## Release gates

The additive Projects schema was deployed and read back in CloudKit Production
on 2026-10-16; the Task-time/reminder fields followed on 2026-10-18. Signed archives,
upload history, physical-device synchronization and notification-delivery checks
remain required; see [Release process](../RELEASE.md).
