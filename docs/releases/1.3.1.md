# ThruFlow 1.3.1

App version **1.3.1**, build **12**. Released on **September 21, 2026**.

## Connectors

- Assign Apple Reminders lists and Todoist projects to individual Areas. An Area
  can receive multiple sources; each source has one destination. Existing Tasks
  keep their Area and focus history.
- Fixed active Toggl Track projects missing from the project picker.
- Automatic connector synchronization no longer triggers Keychain permission
  dialogs. Toggl setup explains API tokens and secure storage before requesting
  access to saved credentials.
- Each connector is labeled Beta on Mac and iPhone.

## Tasks, Habits, and Flow

- Fixed duplicate Habit recovery during live updates and synchronization.
- Manually created Tasks in Habit Areas remain independent Tasks.
- Flow time-distribution bars stack from right to left to make each Task or
  Area's share easier to compare.
- Added Task context menus to Flow on Mac, with Task and Habit headings linking
  to their corresponding lists.
- Suppressed the one-hour reminder when focus time is manually extended beyond
  one hour.

## Interface and synchronization

- Removed unwanted bottom backgrounds on iPhone and fixed the Mac History header
  extending into adjacent navigation areas.
- Completed Japanese, English, and Russian localization updates and adjusted
  compatibility with the SDK 27 toolchain.
- Deployed the missing Habit occurrence field to Production CloudKit; the
  maintainer confirmed that Mac/iPhone synchronization recovered afterward.

## Notes

- Connectors remain in beta. Toggl exports new completed focus time only; it does
  not import history or propagate later edits/deletions to exported entries.
- Update both Mac and iPhone to 1.3.1 for consistent handling of independent
  Tasks in Habit Areas.
