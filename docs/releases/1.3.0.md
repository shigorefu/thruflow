# ThruFlow 1.3.0

[Download on the App Store](https://apps.apple.com/app/id6798609191)

Released on GitHub on September 15, 2026 (JST). App version **1.3.0**, build **11**.

## コネクタ

- AppleリマインダーとTodoistからタスクを取り込み、チェック形式のタスクの完了・未完了を双方向に同期できます。
- Toggl Trackへの集中時間の送信に対応しました。分野とプロジェクトを紐づけると、有効化後にこの端末で開始したフローの完了後に集中時間を送信します。
- 接続情報は端末のKeychainに保存されます。

## 統計

- 複数の分野を選んで集計できます。
- 月の推移は日ごとに表示され、移動平均と日付ごとの詳細を確認できます。
- タスク別では日ごと、分野別ではタスクごとの時間の内訳を表示します。
- 自由に選んだ期間のDotsは、選択した日だけを表示します。
- カレンダーの日付のずれや、Macでのスクロール時の負荷を改善しました。

## フローとタスク

- タイムラインで集中ブロックの終了予定を表示するか選べます。休憩は経過時間のみ表示します。
- Macのフロー表示は、ウィンドウが非アクティブになるとぼかされ、分野の色は右から徐々に切り替わります。
- タスク入力の候補表示と配置を改善しました。`@`では最近使った分野を最大5件表示します。
- 習慣の進捗、実行中のフローの編集、完了操作の応答性などを修正しました。
- MacとiPhoneの見た目や日本語表記を揃えました。

## Known limitations

- Toggl sends new completed focus time only; it does not import past history or
  propagate later edits/deletions to exported entries.
- The Toggl project-selection and startup Keychain fixes developed for **1.3.1**
  are not included in this build. Some active Toggl projects may be missing from
  the picker, and macOS may request Keychain access during startup.
- Official signed binaries are distributed through the App Store. GitHub provides
  source archives for the shipped commit `36bf54c2b21091c7b031fbfd2f408d627be0b53e`.
