# ThruFlow 1.3.0

[Download on the App Store](https://apps.apple.com/app/id6798609191)

Released on GitHub on September 15, 2026 (JST). App version **1.3.0**, build **11**.

## Connectors

- Import tasks from Apple Reminders and Todoist, with two-way synchronization
  of completion and reopening for Check tasks.
- Export focused time to Toggl Track. Map Areas to projects to send completed
  focus segments from Flows started on this device after enabling the connector.
- Connection credentials stay in the device Keychain.

## Statistics

- Select multiple Areas to include in reports.
- Month trends show every day, with a moving-average line and date details.
- Task breakdowns show time by day; Area breakdowns show time by Task.
- Custom Dots ranges display only the selected days.
- Fixed calendar date offsets and improved scrolling performance on Mac.

## Flow and Tasks

- Choose whether the timeline shows the planned end of a focus block. Rest
  displays elapsed time only.
- The Mac Flow stream blurs when its window is inactive, and Area color changes
  gradually sweep in from the right.
- Improved Task input suggestions and their placement. Typing `@` suggests up
  to five recently used Areas.
- Fixed Habit progress, active Flow editing, and responsiveness when completing
  Tasks.
- Aligned Mac and iPhone presentation and made Japanese terminology consistent.

## Known limitations

- Toggl sends new completed focus time only; it does not import past history or
  propagate later edits/deletions to exported entries.
- The Toggl project-selection and startup Keychain fixes developed for **1.3.1**
  are not included in this build. Some active Toggl projects may be missing from
  the picker, and macOS may request Keychain access during startup.
- Official signed binaries are distributed through the App Store. GitHub provides
  source archives for the shipped commit `36bf54c2b21091c7b031fbfd2f408d627be0b53e`.
