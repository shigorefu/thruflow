# Roadmap

## 1.4.0 (14) — released

App Store publication was confirmed by the maintainer on 2026-10-30. This version includes the work previously planned as 1.3.2.

- Optional Projects within Areas, including one Habit per Project.
- Task times and reminders, with quick capture and native timing controls.
- Partial Habit completion statistics and independent daily progress.
- Task name, Project and result capture before completion or Task switching.
- Segmented timer colors and rest based on actual work and recovery.
- Shared Task/Area commands, archive restoration and connector export feedback.
- Expanded iPad/iPhone Duo layouts and preserved task drafts.
- Simplified and Traditional Chinese, localized month names and new demo assets.
- Protected GitHub Actions delivery to App Store Connect.

See [release notes](releases/1.4.0.md) for user-facing changes and
[Release](RELEASE.md) for actual checks and outstanding verification.

## Deferred — no committed release date

- APNs infrastructure, webhooks and remote Live Activity delivery.
- Writing external Task titles or dates back to providers.
- Local recurrence generation for external Tasks.
- Toggl history import and propagation of later history edits/deletions.
- Additional providers and connector management on Watch.
- Any new pricing or optional paid services.

These are deferred possibilities, not promised features. New behavior requires
an explicit product decision before implementation.
