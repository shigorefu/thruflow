# Support

ThruFlow is preparing its first TestFlight release. Please check existing issues before opening a new one.

## Before reporting a problem

1. Update to the newest available TestFlight build.
2. Restart ThruFlow and the affected Apple device.
3. Confirm that iCloud Drive is enabled when the problem involves synchronization.
4. Note the app version/build, device model, OS version, and exact reproduction steps.
5. Remove private Task names, notes, screenshots, and exported data that you do not want to publish.

## Get help

- In ThruFlow, open `Settings > Feedback > Send Feedback` to choose a GitHub report template.
- TestFlight testers can also submit a screenshot or use the TestFlight app; this includes useful build and device context.
- Use [GitHub Issues](https://github.com/shigorefu/thruflow/issues/new/choose) directly for reproducible bugs and feature requests.
- Use the repository's bug template and attach a screen recording or diagnostic log only when it contains no sensitive information.
- For a security or privacy vulnerability, do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## Known release requirements

- iCloud synchronization requires a signed build and a supported Apple account configuration.
- Simulator and unsigned diagnostic builds intentionally use local-only storage.
- The Apple Watch companion requires a compatible paired iPhone and supported watchOS version.

ThruFlow is maintained as an open-source project, so response times are not guaranteed.
