# ThruFlow

[English](README.md) · **日本語**

ThruFlow / スルフロは、Appleデバイスでの集中作業と習慣づくりを支える、無料のオープンソースアプリです。柔軟に調整できるポモドーロタイマーで、作業に使った時間をタスクの進捗として可視化します。

**[App Storeで入手](https://apps.apple.com/app/id6798609191)** · **バージョン1.4.0** · [更新内容](docs/releases/1.4.0.md)

| デバイス | 対応OS |
| --- | --- |
| Mac | macOS 14.0以降 |
| iPhone・iPad | iOS/iPadOS 17.0以降 |
| Apple Watch | watchOS 10.0以降 |

## 主な機能

- **柔軟なポモドーロタイマー。** 「短め」「標準」「じっくり」から開始時の長さを選び、タスクの難しさや自分のペースに合わせて調整できます。途中でタスクを切り替えても、タイマーはリセットされません。決めた時間は何かに取り組み、作業と休憩のリズムを保つことを大切にしています。
- **タスク・分野・プロジェクト。** 「仕事」「学習」など、継続的に取り組む活動を分野として整理できます。分野の中にプロジェクトを作れば、達成したい目標に向けて関連するタスクをまとめられます。タスクには時刻と通知も設定できます。
- **習慣づくり。** 分野やプロジェクトに、スケジュールと目標を持つ習慣を設定できます。タスクが自動で作成され、統計では継続状況や達成率を確認できます。途中まで進めた分も達成率に反映されます。
- **すばやいタスク追加。** 作業の手を長く止めずに、思いついたタスクを書き留められます。
- **履歴と統計。** 集中記録と休憩のタイムラインで、一日の流れを振り返れます。日・週・月・年ごとに、タスク・分野・プロジェクト別の時間配分を確認できます。
- **iCloud同期。** データはデバイス内に保存され、個人のiCloudデータベースを通じて同期されます。ThruFlowのアカウント登録は不要です。
- **Appleデバイスとの連携。** iPhone・Macのウィジェット、ライブアクティビティ、Dynamic Island、Apple Watchのコンパニオンアプリに対応しています。

## はじめ方

1. App StoreからThruFlowをインストールします。
2. 「仕事」「学習」などの分野を作り、最初のタスクを追加します。共通の目標を持つタスクが増えたら、あとからプロジェクトにまとめることもできます。
3. フロー画面でタスクを選び、タイマーを開始します。作業に合わせて時間を調整したり、タスクを切り替えたりできます。
4. 休憩するときは作業の結果をメモするか、メモを入力せずに進み、休憩を開始します。
5. 履歴と統計で進捗を振り返ります。定期的に続けたい活動には、スケジュールと目標を決めて習慣を設定します。

基本的な流れ：

```text
分野 -> タスク -> 集中記録 -> 集中した時間 -> 進捗 -> 統計
```

## 外部サービス連携

Mac・iPhone・iPadで、以下のサービスに対応しています。

- **Appleリマインダー** — 選択したリストから未完了のタスクを取り込みます。
- **Todoist** — 選択したプロジェクトから未完了のタスクを取り込みます。
- **Toggl Track** — 集中時間を記録したデバイスから、連携先のTogglプロジェクトへ完了した作業時間を送信します。

リマインダーとTodoistのチェック式タスクでは、完了する操作と未完了に戻す操作を双方向に同期します。アクセストークンはデバイスのキーチェーンに保存されます。

外部サービス連携はベータ版です。設定方法と制限については、[連携ガイド](docs/CONNECTORS.md)をご覧ください。

## このプロジェクトについて

自分と自分のAppleデバイスのために作っている、個人プロジェクトです。既存のポモドーロアプリには、求めていた使い心地がなかったり、有料だったりしました。そこで、自分に合ったペースで作業し、休憩を取り、習慣を続けるための、無料でオープンソースのツールを作ることにしました。

ほかのプロジェクトを土台にせず、リバースエンジニアリングも行わず、ゼロから開発しています。アイデア、UI、開発の方向性は私が決めています。コードの作成、ローカライズ、テストは、AIエージェントを使って自動化しています。

## ソースからビルドする

ローカル開発にはXcode 27.1を使用しています。アプリはAppleのシステムフレームワークで構成されており、実行時にサードパーティ製ライブラリを必要としません。

1. リポジトリをクローンし、Xcodeで`ThruFlow.xcodeproj`を開きます。
2. `ThruFlow`、`ThruFlow iOS`、`ThruFlow Watch`のいずれかのスキームを選びます。
3. CloudKitを使わずにローカルで動かす場合は、起動引数に`--local-store`を追加するか、`THRUFLOW_DISABLE_CLOUDKIT=1`を設定します。
4. iCloudに対応した署名付きビルドを作る場合は、自分のApple DeveloperアカウントでDevelopment Team、Bundle ID、App Group、CloudKitコンテナを設定します。

テストコマンドは[開発への参加ガイド](CONTRIBUTING.md)、Releaseビルドのコマンドは[リリースガイド](docs/RELEASE.md)に記載しています。同期の確認方法は[CloudKitガイド](docs/CLOUDKIT.md)をご覧ください。

変更はCIで検証し、`main`ブランチは保護しています。App Store Connectへのビルドのアップロードには[TestFlightへの自動配信](docs/TESTFLIGHT.md)を使用しています。公開には、別途の動作確認とAppleの審査が必要です。
