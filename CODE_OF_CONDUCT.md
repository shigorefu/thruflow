# Code of Conduct

## Our standards

ThruFlow welcomes respectful, constructive participation. Examples of positive behavior include empathy, clear technical feedback, respect for differing experience and language ability, and attention to user privacy.

Harassment, discrimination, threats, sexualized attention, doxxing, publication of private user data, and sustained disruptive behavior are not acceptable in project spaces.

## Enforcement

Maintainers may edit or remove comments, commits, code, issues, and other contributions that violate these standards. Temporary or permanent participation restrictions may be applied when necessary.

For a confidential conduct report, use GitHub's private **Report a vulnerability** channel and prefix the title with `[Conduct]`. Maintainers will handle the report privately and disclose information only as needed to investigate and respond.

This policy applies in repository spaces and when someone publicly represents the project.
