# Security Policy

## Supported versions

Security fixes are provided for the newest TestFlight or public release. Pre-release source snapshots and older builds may not receive separate fixes.

## Report a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or pull request.

Use GitHub's **Report a vulnerability** action in the Security tab of this repository. Include:

- affected version and platform;
- impact and realistic attack scenario;
- reproducible steps or a minimal proof of concept;
- any suggested remediation;
- whether the issue is already public.

Do not access another person's data, disrupt services, or retain private data while testing. Reports are acknowledged on a best-effort basis; this project does not currently operate a bug-bounty program.

Ordinary crashes, synchronization conflicts, and UI defects without a security impact belong in GitHub Issues.
